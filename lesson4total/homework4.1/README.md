# Grade Correction Tool

A PySide6 desktop interface for a CSV grade-correction workflow. The loading,
bonus calculation, and file-update methods are intentionally left as `pass`.

Run the app from the project directory with:

```powershell
uv run homework4
```

The app loads its external stylesheet from `src/homework4/style.qss`. Replace
`REPOSITORY_URL` in `src/homework4/__init__.py` with the project’s GitHub URL.
